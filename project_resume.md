**End-to-End Real-Time Water Quality Prediction Platform** | *Python, TensorFlow, FastAPI, Streamlit*
*Lead Developer & Machine Learning Architect*

Architected and deployed a complete, production-ready machine learning pipeline designed to predict environmental safety hazards in real-time by analyzing continuous chemical sensor streams.

*   **Model Architecture:** Designed and trained a Long Short-Term Memory (LSTM) neural network using TensorFlow/Keras to process 24-hour time-series sequences. *   **Interactive Dashboard:** Developed a real-time monitoring frontend using Streamlit and Matplotlib. Enabled stakeholders to simulate extreme pollution anomalies, visualize 24-hour predictive trends, and monitor dynamic WQI (Water Quality Index) safety thresholds.
*   **System Reliability:** Implemented fail-fast asset loading mechanisms and zero-variance detection algorithms to ensure high system reliability and graceful degradation during sensor failures.
